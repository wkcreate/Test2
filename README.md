# Для коханої ❤️ — гра «Сортування кольорів»

Веб-гра (PWA): 1000 рівнів, хард-режим, магазин, теми, подарунок дня. Працює офлайн, ставиться на екран телефону.

## Публікація на GitHub Pages
1. Створіть публічний репозиторій і завантажте **всі файли** з цієї папки в корінь (Add file → Upload files).
2. Settings → Pages → Source: *Deploy from a branch* → гілка `main`, папка `/ (root)` → Save.
3. Через 1–2 хвилини гра відкриється за адресою `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПО/`.
4. На телефоні відкрийте адресу в Safari (iPhone: «Поділитися» → «На екран Домой») або Chrome (Android: ⋮ → «Установить приложение»).

## Файли
`index.html` — уся гра · `manifest.webmanifest` — параметри додатку · `sw.js` — офлайн-режим · `icon-192.png`, `icon-512.png` — іконки

## Що можна змінити в `index.html`
- `PHOTO` — фото на заставці (data-URI) · `MSG` — повідомлення після кожних 10 рівнів
- `SPECIAL.d` — особлива дата у форматі `"ММ-ДД"` (наприклад `"09-21"`), у цей день гра вітає й дарує 100 монет · `SPECIAL.t` — текст вітання
- Ціни — `ITEMS` і `T` (теми)

## Оновлення
Після зміни файлів на GitHub змініть версію кешу в `sw.js` (`lovesort-1.0.0` → `lovesort-1.0.1`). Новий варіант підтягнеться при наступному запуску з інтернетом.

## Збереження
Прогрес (рівень, монети, партія, покупки) зберігається автоматично в `localStorage` браузера на цьому телефоні. Якщо очистити дані сайту або перейти на інший телефон — прогрес почнеться заново.
